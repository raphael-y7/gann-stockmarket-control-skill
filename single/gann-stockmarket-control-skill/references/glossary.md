# GLOSSARY — 《江恩股市操盘术（专业解读版）》共享术语词典

> 阶段 3 产出；来源：candidates/glossary.md（21 条，均经合并转写稿行号核验）。点数口径均为 1920 年代美股绝对价位（1点=1美元）。

| 术语 | 英文 | 作者的定义（原文依据） | 与常识用法的差异 |
|---|---|---|---|
| 看盘 | Tape Reading | 依股市记录研究股票涨落、判断强弱与买卖时机的心理活动（L383）；主张收盘后凭高低价记录复盘（L437） | ≠盯实时行情；"直觉=瞬时推理"，行家立即行动不事后找理由 |
| 大盘 | The Tape | 收录每一股买进卖出的记录带，"买进或卖出的每一股在大盘上都有记录"（L1626） | ≠股票指数；指数只是大盘的统计切片 |
| 贴现 | Discount | 股价提前半年至一年反映未来事件；"利好消息出现而股价开始下滑=已被贴现"（L476） | 比有效市场更行为化：由内部人先知先觉的买卖完成 |
| 吸筹 | Accumulation | 大资金低位区间悄悄买入，痕迹=区间+时间+量三要素；时长与行情幅度成正比 | 非泛指"主力买入"；想吸筹的人会设法不让人知道 |
| 派发 | Distribution | 内部人高位区间分批卖给公众，伴随利好宣传、放量滞涨、区间反复震荡 | 派发期股价表面"最强"（人人谈繁荣），与直觉相反 |
| 行情变化图 | Stock Market Graphs | 月（尽量多年）/周（半年到一年）/日（30~60天）三级高低点记录图；每天15~20分钟维护 | 日图假行情多，必须服从周月图；点评：软件可替代手绘 |
| 成交量 | Volume | "蒸汽之于蒸汽机、汽油之于汽车"；必须按已发售股本总量衡量（换手视角） | 绝对量无意义；点评转译为A股换手率口径（>7%警觉，经验值） |
| 七个行动区域 | Seven Zones | 以内在价值为中枢、上下各三区的价格行为带；各区配许可动作 | 非百分比通道，无量化边界（须以个股为准） |
| 累进的高位和低位 | Progressive Highs and Lows | 顶底序列逐级抬高=涨势、逐级降低=跌势；日/周/月/年通用（L1540） | 趋势的定义即判定法，不另设趋势指标 |
| 点 | Points | 1点=1美元价位变动；止损3~5点、反向运动5~7点、金字塔间隔10点均为此口径 | 绝对价位口径，A股须按百分比/波动率归一（点评明示江恩不用百分比） |
| 金字塔式交易 | Pyramid Trading | 首仓后每顺行10点递减加仓（100→50→30→20→10股）+止损跟进 | 只顺浮盈方向；与摊平严格对立 |
| 止损单 | Stop Loss Order (G.T.C.) | 给经纪人的条件委托，触发即按最好价成交；G.T.C.=撤销前一直有效 | 把纪律外包给订单机制；可能成交在更差价位（跳空更甚） |
| 阻力位/支撑位 | Resistance / Support | 恐慌年/繁荣年反复成交的价位序列；跌破支撑序列=失去支持 | 有效性根基是"同一资金多年运作同一价位"的假设 |
| 领头股 | Leaders | 各时期活跃、波动大、被集合资金运作的标杆股；活跃期5~10年 | 按活跃度与走势定义，不按市值/名气；扁平顶=领涨股、陡直顶=后发股 |
| 内部人士与集合资金 | Insiders / Pools | 多年连续运作同一只股票的同一伙大资金；价位重复有效的根基 | 带操纵叙事；点评指现代信息披露下不宜字面理解 |
| 时间因素 | Time Factor | ①可讲：阻力位维持数周不破=支撑有效；吸筹派发时长正比行情幅度；②不可讲：年度预测的周期算法（作者拒绝公开） | 公开层是确认条件、秘密层是预测算法；蒸馏只取公开层 |
| 波动次数/波动频率 | Number of Swings / Frequency | ①箱体内≥5点震荡计数（10~20次=吸筹/派发）；②期货无成交量时以盘中往复次数代理大笔交易 | A股有真实换手/盘口数据，可直接验证而非代理 |
| 套头交易与跨式交易 | Hedging / Straddle | 同时持有两类反向头寸对锁 | 原书禁令：判断不了就退出，"被扯成两半" |
| 强势股与弱势股 | Strong / Weak Stocks | 完全由价格行为定义：抗跌+率先反弹+底抬升=强；不随大盘创新高+破支撑序列=弱 | 不涉基本面；点评：单边市弱势股直接屏蔽 |
| 换手率（点评） | Turnover Rate | 张艺博将"成交量相对股本"转译为A股口径；上涨中单日>7%应警觉（荐股专家经验值，按股磨合） | 原书用"股本轮换次数"，A股用百分比 |
| 资金余量 | Capital Margin | 按股价档位预留的保障资金（100美元股每100股5000美元等）；用途是垫小额亏损+支撑大宗交易，非防10~30点波动 | 1920年代美元口径；A股换算为单笔风险≤3~5% |
