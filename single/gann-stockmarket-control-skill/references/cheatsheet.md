# 决策规则速查 — 江恩股市操盘术（专业解读版）

| 能力 | 一句话规则 |
|---|---|
| 入市准备与看盘节奏（流程第0步） | 看盘节奏由交易周期决定（日短/周中/月长三档）；年交易≤5~6次+每年两次强制休整才准入市。 |
| 看盘纪律与月/周/日三图体系（流程第1步） | 不盯盘，收盘后15~20分钟维护月（全历史）/周（一年）/日（60天）三图；日图服从周月图，防假行情。 |
| 成交量供求诊断（流程第2步） | 量必须相对股本（换手率）衡量：高位放量滞涨=派发预警，缩量止跌=抛压枯竭，同区间5%级震荡10~20次=吸筹/派发进行中。 |
| 七区域阶段定位与极端反向（流程第3步） | 以价值中枢分七区：上方三区渐热至派发（第一信号=无消息开盘跌1~5点），下方三区渐冷至恐慌买进区；舆情一边倒+价格极端=逆向复核。 |
| 标的类型过滤与轮动（流程第4步） | 只做活跃且年振幅达标的类型（20~100点级）；新股繁荣期高价发行须定位投机+速退；跌破支撑序列的老股失去支持即卖。 |
| 个股习性档案与安全位置（流程第5步） | 交易前建档：顶底形态/触及计数/反向运动5~7点；现价距最高近、距最低远=不安全；恐慌年支撑与繁荣年阻力定安全价位，风险缩到2~3点。 |
| 强弱判定与年度名单（流程第6步·选股核心） | 五步判强（熊市抗跌/率先反弹/底部逐月抬升/突破多年阻力/回踩前高获撑）；大盘新高它不新高=弱势黑名单；年初突破上年高点名单=候选池。 |
| 最终顶底判定（流程第7步） | 累进高低位=趋势本身；多年确立区间被突破几乎必走新高新低；双顶三顶计数、尖顶下派发/尖底上吸筹、窄幅久盘位置定多空；时间与幅度成正比。 |
| 低价吸筹股生命周期（流程第7b步·特殊结构） | 多年低位蛰伏+熊市抗跌+突破十年高点=吸筹完成顺势追涨；高位区间反弹五六次不超前高=转空；跌破区间下沿=派发完成。 |
| 开单前12条规则检查（流程第8步·开单闸门） | 一单未下先过12关：资本量→止损→禁过度交易→浮盈提保本→不逆势→有疑虑退出→活跃股→均摊→不设目标价→卖点四问→累积盈余→分红免疫。 |
| 资金与止损管理（流程第9步） | 先算可亏次数（本金÷单笔风险≥10）再开仓；止损单五纪律=每笔必设/不取消/不上移/越早越好/了结才撤；浮盈3~4点提到保本。 |
| 突破买卖执行（流程第10步） | 数月/年确立区间的突破才有效：原底（顶）附近进场+区间外3点止损+二次新高加仓更安全；信号出现即市价行动，不挂小差价限价。 |
| 金字塔顺势递减加仓计划（流程第11步） | 只顺浮盈方向：首仓后每顺行一档（10点≈10%）递减加仓100→50→30→20→10并同步上移止损；吸筹/派发区与顶底10%区禁加；转势之初才启动。 |
| 消息贴现判定与事件反应（流程第12步） | 利好出而价跌=已贴现；突发利空先退出现望半小时再定强弱；股息降低不破前低=买点，高位加息/额外分红=派发信号，市价增发旧股不涨=清仓。 |
| 持仓年度体检与征兆即卖（流程第13步） | 每年至少一次逐只体检：变坏征兆即卖不等清盘；异常高收益先查信用；自绘持仓月度峰谷图；重复触及计数定支撑阻力。 |
| 失败模式排障与运作方法辨析（流程第14步·纠错回路） | 三大致命错误优先级=过度交易>无止损>摊平；盯盘两年改主意1200次；买断/摊平/比例法/套头四法禁用，金字塔唯一推荐；永不满仓（点评）。 |
